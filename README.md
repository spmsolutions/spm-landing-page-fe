# SPM-Soltuin Docs

Visit:

[https://spm-contact.com/](https://spm-contact.com/).

To run docs locally:

1. Clone this repo
2. Navigate to `website` folder inside the repo
3. Run `npm install`
4. Run `npm start`

Deployment is done through GitHub Actions by pushing the code to the main branch.
